# Developer integration skills

Standalone instructions and references for agents building Airwallex integrations in your codebase. These skills are separate from AgentOS and excluded from plugin catalogs.

Install the developer skills with a single command:

```sh
npx skills add airwallex/airwallex-marketplace/plugins/airwallex-dev
```

Select all six skills and your agent in the installer. This installs skill files only, without a plugin or MCP connector configuration.

See the [skill catalog and setup guidance](../../README.md#developer-integration-skills) for available integrations and Developer MCP requirements. Test generated code with sandbox credentials.
