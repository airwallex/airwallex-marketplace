# Airwallex (Deprecated)

> **The Airwallex plugin is now Airwallex AgentOS.**
>
> To ensure you have the latest capabilities, please uninstall this plugin and reinstall as `airwallex-agentos`:
>
> **Claude Code:**
> ```sh
> claude plugin uninstall airwallex@airwallex-marketplace
> claude plugin install airwallex-agentos@airwallex-marketplace
> ```
>
> Update any skill invocations from `/airwallex:…` to `/airwallex-agentos:…`.
